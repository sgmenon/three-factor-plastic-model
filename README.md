This repo is an experiment of a new model architecture that, similar to biological systems, do not use backpropagation for training.

I was inspired by Yann LeCun's talks papers on JEPA where he argues that robotics of the future would not be relying on language model architectures, since they predict words and not physics, in otherwords, they may have a pedantic understanding of physics of systems, as one would get from a textbook but not the natural intuition that a child's seems to get from just observing the world around them. To me, VLA models for robotics is analogous to using F35s fo commute to work. It can work, but its a lot more expensive way to do things. Yann's JEPA architecture, is a machine-learning architecture that resembles an optimal control setup, and that makes it better suited for unstructured learning and for more efficiently predicting physical observations.

While I agree with Yann, I would like to take things a step further. In biological systems, the brain has not been wired with architectures that resemble JEPA or Language Transformer models. Instead, through the process of synaptic exuberance and pruning, it naturally arrives at architectures that may resemble these models, though that is purely specualtive. So in other words, in a mature adult brain, the neurons naturally arrive at an architecture that best suited for the task at hand. Neurons close to the occiputal lobe, which get all the optic nerve connections likely have convolutional style arrangements, while the cerebellum which is our predictive center may have a JEPA style neural arrangement. The key difference is that modern ML models fundamentally try to optimize their neural efficiency by doing back-propagation. This results in a number of features of artifical neural networks that simply do not exist in the natural world - for example, nature's activation functions are largely non-linear, but non-linear activations cause back-propagation to not converge (exploding/vanishing gradients) and hence we have to use linear activation functions. 

In this repository, I'm trying to make a system that trains itself without backpropagation. To do this we need to define our setup

1. **model initial architecture**: Here we have fully connected neurons with non-linear activation functions (ReLU is fine). However, we can't simply stop at fully connected networks, we need a few shortcut connections in order to simulate non linearity. This includes entire layers that are shortcutted (like the Resets do) as well as a few layers that connect in the X axis (not just along the Y axis). This is particularly relevant since I plan on using this network for world prediction just like JEPA, so they emulate the Purkinje Cells of the cerebellum that are highly interconnected. The rest of the neurons are analogous to the granulle cells. No neurons are decactivated initially, they all have low but random values for activation. Having the X axis connections allow a mechanism for producing non-linear functions based on the same input.
2. **reward system**: Since we do not do backpropagation, we need a separate system that is responsible for updating weights and biases. In our setup we will be feeding video at a consistent frame rate, and the job of the network is to predict the next frame. The model will predict deltas. Initially the model will do terribly since it starts with random weights. However each neuron retains a memory of the last inputs it received, its weights and bias setting, and the feedback a the time. After every new frame, the reward system decides of a an input was too high or too low and sends a positive or negative feedback to the neuron it was connected to. This feedback is proportional to the error. The reward system runs down the whole system, and each neuron gets an updated its feedback value. Biases are adjusted based on feedback from each connection, but weights are adjusted only once all feedback from all connections are received. At some point when pruning hits (which happens say once every million inferences or between scenes) connections with very low biases are pruned. Weights are adjusted to be higher every time there is positive aggregate feedback and lower when there is less.
3. **Sleep vs Awake: prioritize inference based on sensory input, vs prioritize learned pathways**: The activation of neurons connected to inputs have a futher gate which can be externally controlled. When we are "sleeping" we deactivate all sensory input and prioritize intenral replay and similarly when we are awake, there is only a one-way connection to memory. The memory is a block LSTMs that are connected to the middle of the network. I don't have a clear understand of how to model this, but i'm thinking that when we are in sleep mode, this data is useful in evaluating if the pruning we did was too aggressive or not.
5. **pruning**: This removes connections where activations are really low, but occassionally pushes certain unactivated connections to active especially if neighboring connections are active. It also removes redundant connections, these are multiple inputs that almost always fire at the same time, so 2 neuron actications that over the course of several runs almost always fired together. One of those is activated and the other is given more the weight. 
6. **focus**: This is the region of interest - the part of the image where prediction scores have the highest value. This is an altogether external neural network that can be trained classically. 


Dataset:
I'm thining we should evaluate this on a small model with a large consistent dataset of video. Simulation would be good, but its also less practical for video, since emualtion engines that are video accurate are extremely expensive to run. Instead we can use HMDB51 which has a 30fs data at uniform resolution, GOPRO or Human3.6M reduced do a consistent framerate. Since the model is small, i'm concerned that it will be sensitive to ISP so more consistent the ISP the better. If the experiement yields good results we can later try and see how good the model is on different ISPs but still a consistent framerate.
